# 黑幕

选中文字后，浮动工具栏里多一个「黑幕」按钮（在「高亮」右边）。被遮住的文字显示成黑条，鼠标移上去才显示内容。正文、表格单元格、数据库文本单元格都能用。

## 安装

1. 从 [GitHub 仓库](https://github.com/chasezhang1999/siyuan-heimu) 下载 `package.zip`。
2. 新建思源工作空间目录 `data/plugins/siyuan-heimu/`，把 `package.zip` **内部的文件**解压进去。
3. 在 设置 → 集市 → 已下载 → 插件 里启用「黑幕」。

## 用法

- **遮住**：选中文字 → 点浮动工具栏里的黑幕按钮。
- **取消**：选中已遮住的文字再点一次；或者把光标放在黑幕里，用快捷键或命令面板执行「切换黑幕」，整段黑幕一起取消（被加粗等格式切开的相邻黑幕也算一整段）。
- **撤销**：Ctrl+Z。
- **快捷键**：默认没有，可在 设置 → 快捷键 → 插件 里给「切换黑幕」绑定。
- 选中被遮住的文字时也会显示内容，方便编辑。
- 表格和数据库里编辑单元格时，思源会开一个精简的小编辑器，它的浮动栏里同样有黑幕按钮。

## 实现方式与兼容性

黑幕就是思源自带的行内文字样式，背景色写成思源「自定义行内样式」的格式：

```
background-color: var(--b3-inline-style-20260930000000-heimu00-background-color, #808080)
```

插件的样式表负责把文字藏起来、悬停时显示。用这个格式是因为表格和数据库单元格写回时，思源只保留这种写法的自定义颜色，其他写法会被过滤掉。

- 不占用「高亮」，高亮和闪卡挖空照常使用。
- 停用或卸载插件后，被遮住的文字显示成中灰底色的普通文字，不会丢内容。导出 PDF 时同样如此。
- 0.1.0 版写的 `var(--siyuan-heimu)` 仍然识别为黑幕。
- 取消黑幕时，所选范围内的文字颜色、背景色等「文字样式」也会一起清除；加粗、链接等不受影响。
- 表格和数据库里的按钮，是在浮动栏弹出时由插件补上去的：思源不会把插件按钮放进这种小编辑器的浮动栏。
